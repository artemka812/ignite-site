# IGNITE

Учебный сайт для сопровождения киберспортивных турниров. Первая демоверсия к 23 октября 2026 года.

Команда П-24-68Б: Чефранов, Восковец, Карелов.

## Что работает

- Главная страница с главным матчем и турнирами.
- Список трёх турниров, поиск по названию, фильтры по игре и статусу.
- Страница каждого турнира: описание, четыре команды, сетка, расписание, результаты и правила.
- Просмотр составов команд через раскрывающиеся блоки.
- Адаптивная вёрстка для компьютера и телефона от 360 px.

Это первый этап: все сведения демонстрационные и хранятся в Python. Регистрации, базы данных, редактирования счёта, автоматической генерации сеток и трансляций пока нет. Надпись «Идёт матч» относится к учебному сценарию, а не к реальному эфиру. Время матчей московское.

## Технологии

Python 3.12–3.14, Django 5.2 LTS, HTML и обычный CSS. Bootstrap, JavaScript, Node.js и отдельная сборка фронтенда не нужны.

## Запуск в Windows

Открыть терминал в папке проекта. Нужен Python 3.12, 3.13 или 3.14, совместимый с Django 5.2.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py runserver
```

Если используется Python 3.13 или 3.14, заменить `-3.12` на нужную версию. При уже созданном окружении первые две команды повторять не нужно. Активировать окружение и менять Execution Policy не требуется.

Открыть [http://127.0.0.1:8000](http://127.0.0.1:8000). Остановить сервер: `Ctrl+C`.

База на этом этапе не используется, миграции и создание администратора не нужны.

## Проверка

```powershell
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\python.exe manage.py test
```

Для ручной проверки открыть главную, перейти к турнирам, выбрать фильтр, открыть турнир, посмотреть сетку и расписание, раскрыть состав команды. Проверить пустой результат поиска и сброс фильтров. Сузить окно браузера до 360 px: сетка и расписание прокручиваются внутри своих блоков.

## Структура

```text
config/                   настройки и маршруты Django
tournaments/data.py       демонстрационные турниры, команды и матчи
tournaments/views.py      подготовка данных страниц и фильтры
tournaments/tests.py      проверки страниц, фильтров и данных
templates/                шаблоны страниц
static/css/site.css       оформление и адаптивная вёрстка
```

## Следующие этапы

База данных и административная панель, регистрация, профили команд, заявки, генерация сеток, ввод результатов и трансляции добавляются в следующих версиях по плану проекта.

Текущие настройки предназначены для локального показа. Перед публикацией потребуется отдельная настройка хостинга, постоянного `DJANGO_SECRET_KEY`, разрешённых доменов, HTTPS и отключение `DJANGO_DEBUG`.
