# IGNITE

Сайт для организации киберспортивных турниров на Django и PostgreSQL.

## Возможности

- Регистрация по email, вход, профиль игрока и личный кабинет.
- Команды: заявки на вступление, приглашения, состав, передача капитанства.
- Создание турниров, публикация, приём и проверка заявок команд.
- Олимпийская и круговая системы, случайный и ручной посев, проходы без игры, изменение пар до старта.
- Автоматическое продвижение победителей, расписание, календарь и фильтр «мои матчи».
- Ввод счёта, история исправлений, подтверждение результата капитанами.
- Таблица результатов, статистика команд и игроков по сыгранным матчам.
- Плееры YouTube/Twitch, эфиры, архив и поиск матчей.
- Админка, разграничение прав и резервное копирование PostgreSQL.

Прежний тёмный интерфейс IGNITE сохранён: молния, лаймовые акценты, карточки игр. Все основные действия доступны через сайт.

## Локальный запуск в PowerShell

```powershell
cd D:\projects\ignite-site
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe configure_postgres.py
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py createsuperuser
.\.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8000
```

Если окружение и подключение уже настроены, достаточно последних миграций и запуска сервера. Мастер настройки нужен только при первом запуске. Пароли вводятся локально; `config.local.ini` исключён из Git.

Сайт: http://127.0.0.1:8000/ · Админка: http://127.0.0.1:8000/admin/

Необязательные примеры: `python manage.py seed_demo`. Команда не удаляет данные и не перезаписывает существующие записи; созданные ею аккаунты имеют неиспользуемые пароли.

## Как провести турнир

1. Зарегистрироваться. В кабинете включить режим организатора.
2. Создать турнир и опубликовать его, чтобы открыть приём заявок.
3. Капитаны создают команды, собирают состав и подают заявки.
4. Организатор принимает команды, задаёт посев и строит сетку. При необходимости меняет стартовые пары и время матчей.
5. Запустить турнир и вносить результаты в карточках матчей. Победители переходят дальше автоматически.
6. Добавить ссылки на эфиры. После завершения всех встреч турнир автоматически получает статус «Завершён».

## Проверки

```powershell
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\python.exe manage.py makemigrations --check --dry-run
.\.venv\Scripts\python.exe manage.py test --keepdb --noinput
.\.venv\Scripts\python.exe -m pip check
```

Для тестов используется отдельная база `test_ignite_site`; основные данные не очищаются. Мастер подключения подготавливает обе базы.

## Основные файлы

`tournaments/models.py` — данные и ограничения; `services.py` — сетки, счёт, статистика; `community.py` — пользователи и команды; `views.py` — турниры, расписание, матчи и эфиры. Шаблоны находятся в `templates/`, оформление — в `static/css/site.css`.

Документация: [база данных](docs/database.md), [права и регламент](docs/roles-and-rules.md), [развёртывание](docs/deployment.md).

Минимум форматов из ТЗ реализован: single elimination и round robin. Double elimination, Discord/Google и email-рассылки не подключены. Для внешних плееров нужен интернет; Twitch требует HTTPS и правильный домен на опубликованном сайте. Публикация на хостинге выполняется отдельно.
