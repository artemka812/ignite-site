# Права и проведение турнира

| Роль | Возможности |
|---|---|
| Гость | Списки, сетки, расписание, календарь, эфиры, профили, архив |
| Игрок | Профиль, создание команды, заявка на вступление, ответ на приглашение, свои матчи |
| Капитан | Состав своей команды, приглашения, передача капитанства, заявка на турнир, подтверждение результата |
| Организатор | Свои турниры, приём команд, посев, пары, расписание, счёт и эфиры |
| Администратор | Модерация через Django admin; суперпользователь управляет любым турниром |

Капитан определяется связью с командой, а не выбранной при регистрации ролью. Организатором можно стать в своём кабинете; это не даёт staff/superuser и доступа к чужим турнирам. Проверки прав выполняются сервером.

## Подготовка и старт

Организатор создаёт черновик, публикует его, принимает заявки. Для команды проверяются состав и лимит участников. Перед генерацией нужны минимум две принятые команды. Посев бывает случайным или по заданным номерам. После генерации заявки закрываются; существующие матчи не пересоздаются. До старта можно менять начальные пары олимпийской сетки и время будущих встреч.

## Олимпийская система

После поражения команда выбывает; победитель автоматически попадает в следующую пару. Сетка дополняется до степени двойки проходами без игры. Они не считаются сыгранными матчами в статистике. Итоговое место зависит от достигнутого раунда и результата финала.

## Круговая система

Каждая команда играет с каждой один раз: всего n × (n − 1) / 2 встреч. При нечётном количестве команд одна пропускает тур. Победа приносит 3 очка, поражение — 0. Сортировка: очки, разница карт, название команды для устойчивого порядка при полном равенстве. Дополнительных матчей для разрешения равенства система автоматически не назначает.

## Результаты и исправления

Поддерживаются BO1, BO3, BO5. Завершённая серия должна иметь победителя и допустимый счёт. Организатор может исправить результат, пока следующие зависимые матчи не начались. История содержит автора, время, старый и новый счёт. Изменения выполняются в транзакциях с блокировкой турнира. Ошибка не оставляет частично сохранённый результат.

Капитан подтверждает результат только своей команды. Подтверждение относится к конкретной редакции счёта; после исправления нужно подтвердить заново. В момент начала игры сохраняется состав команд, чтобы переход игрока в другую команду не менял историю статистики.

## Эфиры

Организатор привязывает к матчу ссылку YouTube или Twitch и выбирает статус. Сайт строит iframe только для разрешённых адресов платформ. Если встроенный просмотр недоступен, остаётся ссылка на трансляцию. На узких экранах Twitch открывается по ссылке из-за минимальной ширины его плеера.
